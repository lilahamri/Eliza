# Modèle économique - StuddyBuddy

## Stratégie de monétisation : Freemium + B2B

### Offre gratuite

- 10 questions par jour maximum
- Commandes `!aide` et `!reset` uniquement
- Réponses guidées basiques
- Historique limité à 1 heure

### Offre premium élève

- Questions illimitées
- Commandes `!examen` et `!exercice`
- Mode révision avancé
- Historique illimité
- Statistiques par matière
- Prix : 4,99 euros par mois ou 39,99 euros par an

### Offre professeur solo

- Toutes les fonctionnalités premium
- Mode professeur pour créer des évaluations
- Export des réponses élèves en CSV
- Tableau de bord personnalisé
- Prix : 9,99 euros par mois

### Offre professeur pro

- Jusqu'à 300 élèves
- Statistiques détaillées par classe
- Support prioritaire
- Prix : 19,99 euros par mois

### Offre établissement petit collège

- Moins de 300 élèves
- Tous les comptes premium inclus
- Dashboard principal
- Prix : 1500 euros par an

### Offre établissement collège moyen

- 300 à 600 élèves
- Tous les comptes premium inclus
- Dashboard principal
- Support dédié
- Prix : 2500 euros par an

### Offre établissement grand lycée

- 600 à 1000 élèves
- Tous les comptes premium inclus

- Formation incluse
- Prix : 4000 euros par an

### Offre groupe scolaire

- Plus de 1000 élèves

## Seuil de rentabilité

Les coûts fixes mensuels pour la première année sont de 320 euros.

Le revenu mensuel nécessaire pour atteindre la rentabilité est donc de 320 euros.

Avec un panier moyen de 5 euros en conversion du gratuit vers le premium, il suffit de 64 utilisateurs premium.

Avec un panier moyen B2B de 2000 euros, un seul établissement tous les 6 mois suffit.

**Conclusion** : La rentabilité est atteignable dès le premier mois avec une stratégie B2B agressive.

| Donne la réponse directement | Oui | Non, approche pédagogique |

**Différenciation claire** : StuddyBuddy n'est pas un concurrent direct de ChatGPT. Il est complémentaire avec une approche pédagogique versus réponse brute.

## Leviers de rentabilité

1. B2B établissements : forte valeur ajoutée, faible coût d'acquisition
2. Freemium bien dosé : gratuit suffisant pour tester, premium pour les fonctionnalités avancées
3. Optimisation des coûts API Mistral : mise en cache et limite de tokens
4. Scalabilité : marge brute supérieure à 85 pourcent dès la deuxième année
